David Wings Ledger Architecture

Offline-first cashier ledger: shared core, three runtimes, backup file as the only bridge

One core, three runtimes

  • • core/ holds all rules over a tiny SQL adapter
  • • adapters/ swap node:sqlite, Capacitor SQLite, D1
  • • public/ UI is identical everywhere

Independent data

  • • Tablet, dev server and Cloudflare never sync
  • • Backup JSON is the only bridge
  • • Uninstalling the app erases its database

Online security

  • • Cloudflare Access handles login
  • • Worker re-verifies the Access token
  • • Not configured means 401 for everything
